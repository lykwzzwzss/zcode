# native-context-runtime

Runtime 是活跃上下文的唯一所有者。本模块规划区间、构造摘要 DAG、保留稳定前缀，并通过现有工具入口发起压缩或读取原文。

- 摘要只引用直接成员及子边界，成员使用持久化 id；不能把运行时位置当作消息 id。
- 区间外消息和未改写的摘要保留原顺序与正文。按 token 预算保留摘要，超预算的旧节点进入更高一层。
- 原子提交成功后先同步更新 Runtime，再发布边界和完成事件；后续事件失败不得重试已提交的摘要。
- 读取只经 SessionStorePort.contextArchive；缺少端口时报配置错误，不回退全量 messages()。toFile 权限沿用工作区写入路径，且每次只写当前页。
- 读取/导出异常原样上抛，端口显式 failed 也进入 executor 的统一失败路径；不得记录成功事件或成功计量。
- 损坏的压缩记录阻止恢复；摘要模型仅明确的目录校验失败可回退，目录/工厂内部异常不得降为警告。

工具发现通过 tool-discovery 公共入口；数据库和文件 IO 由 adapters 执行。重启、fork 和 rewind 从持久化摘要记录恢复同一逻辑链。
